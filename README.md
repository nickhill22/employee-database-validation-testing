# Employee Database Validation & Testing

## Project Overview

This project demonstrates basic employee database validation and testing using MySQL and SQL.

## Tools Used

- MySQL
- SQL
- Microsoft Excel

## Objectives

- Prepare employee test data
- Perform database validation
- Check missing and invalid data
- Execute SQL queries
- Verify expected and actual results
- Document test cases and results

## Testing Performed

- Employee record validation
- Missing value checks
- Salary validation
- Employee status validation
- Duplicate record checks
- Department-based data validation

## Project Files

- `Employee Database Validation using SQL.sql` – SQL database and validation queries
- `Employees database validation(test-case sheet).xlsx` – Test cases and test results

## Key Skills

SQL, MySQL, Database Testing, Data Validation, Test Data Preparation, Test Case Documentation
